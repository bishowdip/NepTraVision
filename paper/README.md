The manuscript. Start in Markdown (`outline.md`) for fast drafting; move to LaTeX
(`main.tex`) when targeting a specific venue template (IOEGC / IEEE).

- `outline.md` — the section-by-section skeleton with notes on what each section
  must contain (mirrors `docs/05_experiment_protocol.md §7`).
- `figures/` — final figures pulled from `results/figures/`.
- `references.bib` — bibliography (add as you do the literature review, M0/W2).

Venue targets: IOE Graduate Conference (verify eligibility) · regional IEEE
conferences · a low-resource / developing-context CV or applied-ML workshop · arXiv
preprint + Zenodo dataset DOI. See `docs/00_project_charter.md`.
